# ドキュメント

## 実装計画 (`docs/plans/`)

機能追加や改修などのタスクごとの実装計画は、リポジトリルートに単一の `PLAN.md` を置かず、`docs/plans/` 配下にタスク内容ごとのファイルとして分離して管理します。

### 命名規則・記載ルール

- `docs/plans/<task-slug>.md`（ケバブケースの英語スラッグを推奨）
  - 例: `docs/plans/history-import-export.md`
- 各ファイルの冒頭にステータス記載枠（`- **ステータス**: 未着手 | 進行中 | 完了` など）を設け、進捗に応じて更新する
